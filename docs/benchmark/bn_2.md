## B2 — Benchmark Datasets

Create deterministic small, medium and large project fixtures.

Include realistic source code, dependencies, documentation, configuration files, generated files and known relevant search targets.

Create a labelled query dataset with expected relevant files and graded relevance where appropriate.

Include fixtures for:

- Initial indexing.
- One-file modification.
- Multiple-file modification.
- File deletion.
- File rename.
- Dependency changes.
- Repeated retrieval.
- Fresh-session context preparation.

Ensure every dataset is versioned and reproducible.

Do not use randomly generated content that changes between runs.
