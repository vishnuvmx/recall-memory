# RECALL — BENCHMARKING SYSTEM RECONSTRUCTION

You are responsible for reconstructing the existing benchmarking infrastructure of Recall.

The existing project uses Benchmark.js. Do not assume it is entirely useless, but critically evaluate whether its current implementation measures real Recall performance.

The objective is to build a reproducible, statistically responsible, application-level benchmarking system.

IMPORTANT RESTRICTIONS:

- Do not modify production functionality unnecessarily.
- Do not generate artificial benchmark results.
- Do not benchmark placeholder implementations.
- Do not use hardcoded performance numbers.
- Do not claim improvements without measurements.
- Do not benchmark only isolated JavaScript functions.
- Do not mix correctness tests with performance measurements.
- Preserve existing useful tests and benchmarks.
