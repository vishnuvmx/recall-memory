## B4 — Retrieval Quality Evaluation

Implement offline retrieval evaluation using labelled ground-truth queries.

Calculate:

- Precision@K.
- Recall@K.
- Mean Reciprocal Rank.
- nDCG@K.

Measure context relevance, unnecessary file retrieval and retrieval coverage.

Compare keyword, vector and hybrid retrieval where those implementations exist.

Report missing ground truth separately from incorrect retrieval.

Never optimize speed by silently sacrificing retrieval quality.
