## B1 — Benchmark Architecture

Design a standalone benchmarking subsystem for Recall.

Evaluate Vitest Benchmarking with Tinybench, Node.js perf_hooks and custom workload runners.

Define:

- Benchmark interfaces.
- Dataset format.
- Workload definitions.
- Execution isolation.
- Environment metadata.
- Statistical calculations.
- Result storage.
- Historical comparisons.
- Report generation.

Keep benchmarking independent from production code.

Do not implement until the architecture is approved.
